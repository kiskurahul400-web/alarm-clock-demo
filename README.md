# Alarm Clock Demo

This repo contains a simple Android alarm app built with Kotlin and Jetpack Compose.

## Features
- Choose a time with a Material 3 time picker
- Set and cancel a one-time alarm
- Android notification when the alarm triggers
- Exact alarm scheduling on supported Android versions

## How to run
1. Open the project in Android Studio.
2. Sync Gradle.
3. Run the app on an emulator or device.

## Notes
- Android 12+ may ask for exact alarm permission before scheduling.
- For the notification to appear on Android 13+, allow notification permission in the app/device settings.
